### `bing_*`: external web and public information

- This MCP family is for public web pages, official sites, tutorials, articles, comparisons, recent updates, and other external information.
- Typical sequence: search first, then fetch/crawl specific pages as needed; continue crawling only when more detail is required.
- Suitable for requests about “latest”, official sources, external comparisons, web materials, and public tutorials. It is not suitable for internal documents or private system data.
- For time-sensitive questions, prefer this MCP instead of relying on memory or treating an internal knowledge base as external search.
